🚀 JumaHub Dashboard (Demo)
JumaHub is a modern and interactive sales analytics dashboard designed to help businesses visualize performance metrics, monitor trends, and track key KPIs in real-time. Built with React, Chart.js, and Tailwind CSS, the dashboard features a dynamic UI with support for dark/light themes, sortable tables, animated KPI cards, and sales trend visualizations.

⚠️ Note: This is a frontend-only demo. It uses static mock data and does not include any backend services or real-time data integration.

📌 Project Status
This project is a static prototype for demonstration purposes.
It does not include backend integration, authentication, or real-time analytics. The data is mocked and used to illustrate UI/UX capabilities.
